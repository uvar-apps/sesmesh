\subsection{Programs}
\label{sec:comparison-programs}

The comparison covers the programs discussed in \cref{sec:intro}, at the
settings the specification prescribes for high-accuracy references:
MSMS~\cite{sanner1996} at a vertex density of at least 20 per \AA$^2$,
NanoShaper~\cite{decherchi2013} at a grid scale of at least 4 per \AA,
EDTSurf~\cite{xu2009edtsurf} at its highest resolution, sesa for analytic
areas~\cite{wang2024sesa}, and ChimeraX~\cite{chimeraxsurface} at grid
spacings of 0.5 and 0.25\Ang{} as the most widely used grid-based
implementation \todo{program versions, build options and exact command

Quan--Stamm mesher~\cite{quan2017} are included}. GPU programs
(QuickSES~\cite{martinez2019quickses}, Hermosilla et

which is not comparable with \cref{tab:large} (different hardware,

\subsection{Protocol}

\begin{itemize}
  \item \textbf{Same input.} Identical atom sets and radii for all programs:
    \sesmesh{} writes the selected atoms with their radii (PQR or
    \code{xyzr}), which every program reads; probe radius 1.4\Ang;
    hydrogens and waters excluded.
  \item \textbf{Same surface.} Cavity handling matched per program
    (external surface only, as MSMS reports by default, vs.\ all components);
    areas and volumes compared per component where the programs report
    them.
  \item \textbf{Matched resolution.} \sesmesh{} spacing $h$ against MSMS
    density $d = 1.5/h^2$ (\cref{sec:density}), NanoShaper grid scale
    $1/h$, EDTSurf and ChimeraX grid spacing $h$.
  \item \textbf{Provenance.} Numbers stored with program version and exact
    command line in \code{tests/\allowbreak data/\allowbreak reference/\allowbreak *.toml}, so continuous
    integration can compare against them without installing the programs.
  \item \textbf{Timing.} \code{hyperfine} with 2 warm-up and 10 measured
    runs, peak resident set size from \code{/usr/bin/time}, on both
    reference machines (Apple Silicon with 8 performance cores; x86-64 with
    8 cores and AVX2).
\end{itemize}

    crashes and time-outs per program, and, for every mesh produced, the

    independent mesh library \todo{choose the independent mesh checker;

  \item \textbf{Performance} on the benchmark set of \cref{tab:perf} at
    matched resolution: wall time and peak memory per program and thread
    count \todo{run the performance comparison on both reference

  \item \textbf{Determinism}: for each multi-threaded program, outputs for

    \cref{sec:intro} into a measurement \todo{run the determinism

  \item \textbf{Normals}: angle between each program's vertex normals and
