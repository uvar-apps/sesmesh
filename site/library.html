02

Quick start

Spheres in, a validated mesh and its statistics out:

Rust
use sesmesh::{compute_surface, mesh, Sphere, SurfaceParams};

let atoms = [Sphere::new([0.0, 0.0, 0.0], 1.7), Sphere::new([3.0, 0.0, 0.0], 1.7)];
let out = compute_surface(&atoms, &SurfaceParams::ses(1.4).with_spacing(0.3))?;
assert!(mesh::validate(&out.mesh).is_ok()); // closed, oriented, manifold
assert_eq!(out.stats.components, 1);

Sphere is a centre and a radius in Å; radius 0 means “ignore”. compute_surface returns a SurfaceOutput with the mesh, its components, statistics and diagnostics.

03

From a file

Read, select atoms, assign radii, mesh, write. Selection follows the CLI defaults (first model, no waters or hydrogens, highest-occupancy alt-locs).

Rust
use sesmesh::export::ply::{PlyOptions, write_ply_path};
use sesmesh::io::{ReadOptions, read_path};
use sesmesh::radii::{RadiusOptions, assign};
use sesmesh::{Diagnostics, Quality, Selection, Sphere, SurfaceParams, compute_surface};

fn main() -> sesmesh::Result<()> {
    let structure = read_path("4hhb.cif.gz", &ReadOptions::default())?;
    let mut diags = Diagnostics::new();
    let atoms = structure.select(&Selection::default(), &mut diags)?;
    let radii = assign(&atoms, &RadiusOptions::default(), &mut diags)?;
    let spheres = Sphere::from_atoms(&atoms, &radii)?;

    let params = SurfaceParams::ses(1.4).with_quality(Quality::High);
    let out = compute_surface(&spheres, &params)?;
    for c in &out.components {
        let kind = if c.is_cavity() { "cavity" } else { "surface" };
        println!("{kind}: {} triangles, {:.1} Å², {:.1} Å³", c.triangles, c.area, c.volume);
    }
    write_ply_path("4hhb.ply", &out.mesh, &PlyOptions::default())?;
    Ok(())
}

Readers: io::read_path, io::read_bytes (PDB, mmCIF, XYZ, PQR, gzip detected by magic bytes); biological assemblies with ReadOptions::assembly. Radius sets: Bondi (default), Alvarez, ProtOr, uniform, or custom rules (radii::RadiusOptions).

Parameters

Rust
use sesmesh::mesh::Decimation;
use sesmesh::{CavityMode, NormalMode, SurfaceParams};

let params = SurfaceParams::ses(1.4)
    .with_spacing(0.25)                    // grid spacing in Å
    .with_cavities(CavityMode::Remove)     // drop internal cavities
    .with_smoothing(2)                     // Taubin rounds + exact re-projection
    .with_remove_fragments(true)           // drop sub-grid fragments (1.1)
    .with_decimation(Decimation::ratio(0.25).with_max_error(0.05))
    .with_max_memory(4 << 30)              // 4 GiB estimate limit …
    .with_auto_coarsen(true)               // … coarsen instead of failing
    .with_normals(NormalMode::Analytic);

What you get back

FieldContent
out.mesh.positions, .normalsVec<[f32; 3]>: vertices on the surface, unit normals into the solvent
out.mesh.trianglesVec<[u32; 3]>, counter-clockwise seen from outside, grouped by component
out.mesh.vertex_atom, .vertex_patch, .vertex_componentNearest input sphere, patch (PatchKind: convex, saddle, concave), component index
out.componentsPer component: vertices, triangles, area, signed volume (cavities negative), Euler characteristic, first triangle
out.statsTotals, spacing used, removed fragments, decimation, the memory guard's estimate, refine evaluations, SIMD kernel, stage timings

Per-vertex colours and per-atom areas, the way the CLI computes them:

Rust
let structure = read_path("1crn.cif", &ReadOptions::default())?;
let mut diags = Diagnostics::new();
let atoms = structure.select(&Selection::default(), &mut diags)?;
let radii = assign(&atoms, &RadiusOptions::default(), &mut diags)?;
let out = compute_surface(&Sphere::from_atoms(&atoms, &radii)?, &SurfaceParams::default())?;

// Colour each vertex by the element of its nearest atom.
let palette = ElementPalette::default();
let elements: Vec<_> = atoms.iter().map(|a| a.element).collect();
let mut options = PlyOptions::default();
options.vertex_colors = out
    .mesh
    .vertex_atom
    .iter()
    .map(|&i| palette.color(elements[i as usize]))
    .collect();
write_ply_path("1crn.ply", &out.mesh, &options)?;

// SES area per atom (Å²), from the triangles nearest to it.
let areas = mesh::atom_areas(&out.mesh, atoms.len());
let exposed = areas.iter().filter(|&&a| a > 1.0).count();
println!("{exposed} of {} atoms expose more than 1 Å²", atoms.len());
assert!(mesh::validate(&out.mesh).is_ok());
06

Engines & trajectories

SurfaceEngine validates parameters once and keeps per-thread buffers between calls; Control adds cancellation (an AtomicBool, honoured within about 100 ms) and progress callbacks per stage.

Rust
use std::sync::atomic::AtomicBool;

use sesmesh::{Control, Progress, Sphere, Stage, SurfaceEngine, SurfaceParams};

fn main() -> sesmesh::Result<()> {
    // Parameters are validated once; per-thread buffers are kept between
    // frames.
    let mut engine = SurfaceEngine::new(SurfaceParams::ses(1.4).with_spacing(0.4))?;
    let cancel = AtomicBool::new(false);
    let progress = |p: Progress| {
        if p.stage == Stage::Mesh && p.done == p.total {
            eprint!(".");
        }
    };
    let control = Control::new().with_cancel(&cancel).with_progress(&progress);
    for frame in 0..10 {
        // Two atoms moving apart: one component, then two.
        let d = 2.5 + 0.6 * f64::from(frame);
        let spheres = [Sphere::new([0.0; 3], 1.7), Sphere::new([d, 0.0, 0.0], 1.7)];
        let out = engine.compute_with(&spheres, &control)?;
        println!(
            "frame {frame}: distance {d:.1} Å → {} component(s), area {:.2} Å²",
            out.stats.components, out.stats.area
        );
    }
    eprintln!();
    Ok(())
}
07

Field queries

SesField answers point queries on the exact surface function: signed distance (negative inside), the closest surface point, the normal and the patch with its atoms — useful for docking scores, probes or your own mesher.

Rust
use sesmesh::field::Patch;
use sesmesh::{SesField, Sphere, SurfaceKind};

fn main() -> sesmesh::Result<()> {
    let spheres = [
        Sphere::new([0.0, 0.0, 0.0], 1.7),
        Sphere::new([3.0, 0.0, 0.0], 1.7),
    ];
    let field = SesField::new(&spheres, 1.4, SurfaceKind::Ses)?;
    // Negative inside the molecule, 0 on the SES, positive in the solvent.
    for point in [
        [-1.7, 0.0, 0.0],
        [1.5, 1.0, 0.0],
        [1.5, 1.5, 0.0],
        [0.0, 3.0, 0.0],
    ] {
        let s = field.sample(point);
        let patch = match s.patch {
            Patch::Convex { atom } => format!("convex (atom {atom})"),
            Patch::Saddle { atoms } => format!("saddle (atoms {atoms:?})"),
            Patch::Concave { atoms } => format!("concave (atoms {atoms:?})"),
            _ => "solvent".to_string(),
        };
        println!(
            "{point:?}: F = {:+.4} Å, {patch}, normal {:?}",
            s.value,
            s.normal.map(|n| n.map(|c| (c * 1000.0).round() / 1000.0))
        );
    }
    Ok(())
}
08

Threads & determinism

sesmesh runs in the current rayon pool. The result is bit-identical for any pool size, so you can trade cores for latency without changing a single byte of output.

Rust
let spheres = [Sphere::new([0.0; 3], 1.7), Sphere::new([3.0, 0.0, 0.0], 1.7)];
let params = SurfaceParams::ses(1.4).with_spacing(0.3);
// sesmesh runs in the current rayon pool: limit it to four threads.
let pool = rayon::ThreadPoolBuilder::new().num_threads(4).build()?;
let out = pool.install(|| compute_surface(&spheres, &params))?;
println!("{} triangles", out.stats.triangles);
09

Errors & warnings

Every fallible call returns sesmesh::Result. Error separates I/O, parse errors (with line and column), invalid input, empty selections, resource limits, cancellation and internal invariants. Non-fatal problems — unknown elements, missing radii, discarded alt-locs — are collected in Diagnostics. The library never prints.

Rust
match read_path("broken.pdb", &ReadOptions::default()) {
    Ok(structure) => {
        let mut diags = Diagnostics::new();
        let _ = structure.select(&Selection::default(), &mut diags);
        for w in diags.warnings() {
            eprintln!("warning: {w}"); // e.g. unknown elements, alt-locs
        }
    }
    Err(Error::Parse { line, message, .. }) => eprintln!("line {line:?}: {message}"),
    Err(e) => eprintln!("error: {e}"),
}
